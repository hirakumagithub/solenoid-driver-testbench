数値シミュレーション手法解説（1 / 4）

なぜ電流 i(t) は解析的に解けないのか？ ― 非線形連成系と状態方程式化

SLIDE 01 / 04

1解析的（手計算）に解けない3つの理由

固定インダクタンスのRL回路なら単純な指数関数 i(t) = (V/R)(1 - e-(R/L)t) で解けますが、可動鉄心ソレノイドは以下の非線形性を含みます。

  • インダクタンスの変位依存性 L(x)：
    ギャップが狭まるにつれ L(x) が指数関数的に急増するため、係数が時間とともに変化する。
  • 電流の2乗に比例する磁気吸引力：
    機械系の駆動力 Fmag = ½ i² (dL/dx) が電流 i の2次式（非線形項）になっている。
  • 電気系と機械系の双方向フィードバック：
    電流がプランジャを動かし（v = dx/dt）、その速度が速度起電力 i(dL/dx)v となって電流を押し戻す。
結論：初等関数による閉じた解析解が存在しない
→ 微小時間 Δt ごとに状態を更新する「数値積分」が必須

2数値計算のための「状態空間モデル」への変換

数値積分ソルバーで扱えるよう、3つの状態変数 y = [ i, x, v ]T の時間微分（1階連立常微分方程式）の形に整理します。

① 電流の変化率（電気回路方程式より）
di/dt = { Veff − R·i − i·(dL/dx)·v } / L(x)
② 変位の変化率（速度の定義）
dx/dt = v
③ 速度の変化率（ニュートンの運動方程式より）
dv/dt = { ½ i² (dL/dx) − k(x + x0) − c·v } / m
※ L(x) と dL/dx はプランジャ位置 x だけで決まる既知の形状特性関数
💡 ポイント：右辺に未知の微分値を含まないため、「今の [i, x, v] を右辺に代入するだけ」で次の瞬間の傾きが計算できます。
State Vector: [i(t), x(t), v(t)]

4次ルンゲ＝クッタ法（RK4）の計算ステップ（Δt = 0.2 ms）と境界条件

SLIDE 03 / 04

51回のバトンパス（tn → tn+1）の中で行う「4回の傾きサンプリング」

インダクタンス急変時でも誤差が蓄積しないよう、1ステップ（Δt = 0.2 ms）内で始点・中点2回・終点の4回、状態方程式の右辺 f(y) を計算して重み付け平均をとります（60fps描画の1フレームあたり20回反復）。

STEP 1：始点の傾き
k1 = f(yn)
現在時刻 tn の確定値 [i, x, v] を右辺に代入して最初の傾きを算出。
STEP 2：中点の傾き①
k2 = f(yn + ½Δt·k1)
k1 で半歩（0.1 ms）進んだ仮の中間地点の値を右辺に入れて傾きを測り直し。
STEP 3：中点の傾き②
k3 = f(yn + ½Δt·k2)
k2 で修正した中間地点の値を再び右辺に入れ、より正確な中点の傾きを算出。
STEP 4：終点の傾き
k4 = f(yn + Δt·k3)
k3 でゴール地点（tn + 0.2 ms）まで仮に進んだ地点の傾きを算出。
STEP 5：重み付け平均で確定
yn+1 = yn + (Δt/6)(k1 + 2k2 + 2k3 + k4)
局所打切り誤差 O(Δt5) の高精度で次の時刻の [i, x, v] を確定し、次へバトンタッチ。

Aスイッチ状態の切替

ゲート信号に応じて印加電圧を切替：
・ON時：Veff = +Vsup（電源駆動）
・OFF時：Veff = −Vd（還流ダイオード順方向降下 0.7V で減衰）

Bダイオードの逆阻止特性

OFF時の還流ループでは、磁気エネルギーが尽きた後に逆流しないよう、i(t) ≤ 0 に達した時点で i = 0, di/dt = 0 にクランプし、実際の整流特性を再現。

Cメカストッパーの変位制限

プランジャの可動範囲 0 ≤ x ≤ 8.0 mm を超えないよう、初期位置（x=0）および固定鉄心吸着端（x=xmax）到達時に速度 v = 0 へ拘束。

🎯 結果：吸着直前の急激な dL/dx と v の増大をRK4が正確に捉えることで、実機特有の「電流ディップ波形」が自然に再現されます。
Sub-step: 200 μs / Accuracy: O(Δt⁵)

【視覚化】4次ルンゲ＝クッタ法（RK4）と勾配場による誤差相殺のメカニズム

SLIDE 04 / 04

Euler誤差: 0.0000 RK4誤差: 0.0000
STEP 1：始点の勾配 k₁（オイラー法と同じ）
k₁ = f(tₙ, yₙ)

出発点での勾配 k₁ だけで最後まで進む（オイラー法）と、真の曲線より上側へ大きく外れます。

STEP 2：仮の中点① での勾配 k₂
k₂ = f(tₙ + ½Δt, yₙ + ½Δt·k₁)

k₁ で半歩進んだ仮の中点は真の曲線より少し上にあるため、その場の勾配 k₂ は緩やか（下向き補正）になります。

STEP 3：仮の中点② での勾配 k₃
k₃ = f(tₙ + ½Δt, yₙ + ½Δt·k₂)

緩やかになった k₂ で再び半歩進むとほぼ真の曲線上に乗り、その地点での正確な勾配 k₃ を得ます。

STEP 4：仮の終点での勾配 k₄
k₄ = f(tₙ + Δt, yₙ + Δt·k₃)

k₃ で終点（tₙ + Δt）まで仮に進み、終点位置での勾配 k₄ をサンプリングします。

STEP 5：4つの勾配を 1 : 2 : 2 : 1 で重み付け平均
yₙ₊₁ = yₙ + (Δt / 6)(k₁ + 2k₂ + 2k₃ + k₄)

k₁ の行き過ぎと k₂, k₄ の緩やかさが相殺され、平均化された直線が真の曲線上の終点へ高精度に着地します。

💡 直感的理解：背景の薄い線分（勾配場 f(t, y)）の通り、「少し外れた仮の中点で逆向きの補正勾配を拾って平均する」ことで曲線誤差を打ち消しています。
